How to paste into Gmail / Outlook:

  1. Click the Copy Signature button above.
  2. Gmail: Settings → See all settings → General → Signature box → Paste (Cmd+V or Ctrl+V) → Save Changes.
  3. Apple Mail: Settings → Signatures → Add new and Paste.
  4. Outlook: Settings → Mail → Signature → Paste.
