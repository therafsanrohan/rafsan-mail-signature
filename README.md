# Rafsan Rohan — Email Signature

Professional HTML email signature for **Rafsan Rohan** (Creative Visualizer & Visual Strategist).

## Features
- **Modern Minimal Design**: Pixel-perfect implementation following Figma / HTML hand-off specs.
- **Table-based Layout**: Compatible with Gmail, Apple Mail, Outlook (macOS / Windows / Web), and mobile email clients.
- **Retina 3x Avatar**: 92px circular crop with transparent PNG mask.
- **Zero External Image Dependencies (Base64)**: Works offline and immediately in browser without broken links.
- **Interactive Action Buttons**: Pill-shaped CTAs with arrow indicators.
- **One-Click Copy**: Built-in copy-to-clipboard functionality for instant pasting into email settings.

## Files
- `index.html` / `rafsan-rohan-email-signature.html`: Main email signature file with preview and 1-click copy.
- `rafsan-rohan-headshot-92px.png`: 92px round avatar (3x retina).
- `rafsan-rohan-headshot-circle.png`: High-resolution circular headshot (512x512).
- `rafsan-rohan-headshot-square.jpg`: High-resolution square headshot.

## How to Use
1. Open `index.html` in any web browser.
2. Click the **"Copy signature"** button.
3. Open your email client settings:
   - **Gmail**: Settings &rarr; See all settings &rarr; Signature &rarr; Create new / Edit &rarr; Paste.
   - **Apple Mail**: Settings &rarr; Signatures &rarr; Add new &rarr; Paste (uncheck *Always match my default message font*).
   - **Outlook**: Settings &rarr; Mail &rarr; Compose and reply &rarr; Email signature &rarr; Paste.
4. Save settings.
